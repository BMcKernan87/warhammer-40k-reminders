# Warhammer 40K Reminders

Standalone Warhammer 40,000 reminder companion. Source import and verification are in progress.

## 11th-edition Necron datasheet import

The roster uses the checked snapshot in `data/necrons-11e-datasheets.json`. After reviewing source changes, run `npm run import:datasheets` to regenerate the TypeScript registry. The test suite first checks that the registry agrees with the snapshot.

### Wahapedia export adapter

Run `npm run import:wahapedia -- /tmp/necron-review` to download the 11th-edition tables. Append `--from-dir /path/to/export` to read a local snapshot. The adapter checks the export revision before and after downloading, hashes its inputs, and joins the faction's datasheets, model composition, pricing brackets, keywords, weapon options, attachments and matched-play detachment data. It writes a roster candidate and a separate rules review file. [Wahapedia export](https://wahapedia.ru/wh40k11ed/Last_update.csv)

Run `npm run check:necron-mfm -- /tmp/necron-review` to compare those files with a pinned, independently maintained scrape of the October 14 Munitorum Field Manual v1.6. Supply the snapshot YAML as a second argument to check it offline. The November 23 export matched all 52 current units, 98 price entries, 31 attachment pairs, 12 detachment budgets and force dispositions, and 42 enhancement or upgrade prices. The checker reports discrepancies before a refreshed candidate is promoted. Individual wargear choices, targeting, timing and reminder behavior require their own source checks and tests. [MFM snapshot](https://github.com/richardsolomou/wh40k-11e-mfm/blob/6eed7b100ae508c1faa76a42bf7b55ecabb59107/data/necrons.yaml)

The checker requires MFM version `1.6` and effective date `2026-10-14`, including for an offline YAML input. Unknown attachment targets, conflicting roles, duplicate identities and orphaned upgrade references fail comparison. The export adapter also rejects unexpected active Necron cards, foreign faction relationships, duplicate selected-source rows and incomplete model, weapon, ability or detachment records. Only cards explicitly sourced from Necrons Warhammer Legends are excluded from the matched-play manifest. Generated runtime records require composition, faction keywords, model profiles and complete prices.

Import still produces review candidates rather than changing live rules automatically. Both candidate and review files are staged before publication, and a caught replacement failure restores the previous pair. Regression tests exercise malformed inputs and a failure during the second replacement. A fresh download of the complete `2026-11-23 01:43:36` export reproduced the previous candidate, review and checked TypeScript registry byte for byte under these stronger checks. The offline comparison validates the supplied data against the pinned version/date contract; it is not independent authentication of an edited local YAML file.

The current [Necrons Faction Pack v1.3, legal from 30 September 2026](https://assets.warhammer-community.com/eng_30-09_wh40k_faction_pack_necrons-1urphgbmpy-wbhocjbaba.pdf) prints **Skyshroud Spearhead** on page 3. The earlier internal `Skysword Spearhead` key is a saved-data alias only; migration keeps roster IDs, equipment, attachments and upgrade selections and coalesces that alias with the canonical name. Page 4 prints **Prelocational Optimiser**, which remains the canonical upgrade name despite the secondary export's `Relocational Optimiser` label. Necron upgrade citations now use this September supplement instead of the superseded June URL. These name and citation checks do not certify every Codex rule or point value: the pack supplements the Codex with seven detachments, eight new datasheets and one Imperial Armour datasheet, and direct access to the current official MFM remains unavailable (HTTP 403).

### Attack windows and surviving formations

The [current core rules](https://assets.warhammer-community.com/eng_01-06_warhammer40k_new40k_core_rules-was6fbu1ix-hfewhmxyiy.pdf) place Fire Overwatch at the end of the opponent's Movement phase (15.08), allow ranged attacks only with ranged weapons (04.01.01), and define attached ability lifetimes in 19.04. The focused regressions check Movement attack and defence reminders, reject Charge-phase Overwatch, and exclude offensive Shooting prompts for formations without a surviving ranged weapon. They also distinguish a surviving source's unit-wide effect from a destroyed model's personal equipment or save.

[Cryptothralls](https://wahapedia.ru/wh40k11ed/factions/necrons/Cryptothralls) and [Tomb Crawlers](https://wahapedia.ru/wh40k11ed/factions/necrons/Canoptek-Tomb-Crawlers) join the original Bodyguard until the battle ends. Formation checks therefore validate the original roster links before filtering casualties. They preserve surviving Leader/Support and retinue membership, retain the relevant Bodyguard ability source while retinue models survive, and reject originally illegal joins even if later losses remove the conflict. Browser regressions reopen both spellings of a saved Skyshroud army and check its separate squads, physical equipment, attachments, upgrades and all eleven printed phase sections.

Persistent detachment effects include their applicable Movement windows: Casket's Stealth, Fulcrum's Wound re-rolls, Annihilation Protocol's AP, Worthy Foes, Ingrained Superiority, Cold Fervour and selected Chrono-impedance protection. Cold Fervour distinguishes the inherent Destroyer Cult benefit, including Nekrosor, from its more restricted conditional recipients. [Deathmarks' Hyperspace Hunters](https://wahapedia.ru/wh40k11ed/factions/necrons/Deathmarks) uses normal reaction shooting, so applicable Hit modifiers and Critical Hit abilities remain available. Overwatch uses snap shooting: Hit modifiers, Hit re-rolls and Critical Hits are excluded, while applicable Wound re-rolls and Critical Wounds remain available. Shooting-phase-only selections and Heavy's own-Shooting restriction are preserved.

Selected effects retain their stated duration after their original source is destroyed. Conditional follow-ups cover the relevant Command selections, pin and movement penalties, duck-for-cover and charge restrictions, Targeting Relay's selected target, Prophet of Destruction's selected formation and Ancient Collector's previously secured objectives; a destroyed source cannot activate them again. Auras still require a surviving source. Follow-up recipients use the original legal formation rather than a reused squad ID or a changed attachment. These reminders describe what to check; they do not assume that a target was selected or that a battlefield condition occurred.

The current [Chronomancer card](https://wahapedia.ru/wh40k11ed/factions/necrons/Chronomancer) prints Blast on its Aeonstave profile, which the weapon cue follows. Its loadout sentence still uses "Chronomancer's stave"; this is a recorded source naming discrepancy, not an independently reconciled Codex rename. The Deathmarks card retains the term "Reinforcements step", whereas the current core rules resolve ingress in the Move Units step; reminder prose retains the card's enemy-arrival trigger without introducing a separate step.

### Saved physical equipment

Saved-model validation and runtime expansion use the same equipment precedence: an explicit squad choice or mixed distribution takes precedence, followed by a legacy unit-wide choice, then the printed default. Consistent old saves remain usable and contradictory physical-model rows fail validation. The fresh 52-card loadout comparison includes 30 option rows across 19 configurable datasheets. Mobile and desktop browser cases reopen inherited Tomb Blade equipment alongside an independently equipped duplicate, edit and reload the duplicate, and print the current reaction effects with all eleven phase bookmarks.

### Transport, reserve and charge conditions

Transport candidates validate original attachments before using the current surviving models. A [Ghost Ark](https://wahapedia.ru/wh40k11ed/factions/necrons/Ghost-Ark) has separate capacity for ten Warrior models and one Necrons Infantry Character model; joined retinues and additional Characters must fit as physical models. Casualties can make a previously oversized unit fit, and a legally attached surviving Support retains its original formation. The [Night Scythe](https://wahapedia.ru/wh40k11ed/factions/necrons/Night-Scythe) carries one whole Infantry unit, so a joined Infantry model can provide that unit keyword only while it survives. Invasion Beams uses those same valid current formations, with its empty-transport, range and engagement conditions retained in the Fight reminder.

The starting reserve allowance deducts every actual Aircraft, including Doom Scythes, before offering optional whole formations, while preserving specific faction exemptions. The current Night Scythe lacks Aircraft and remains an optional reserve selection. Its card still says "Reinforcements step"; Quantum Invader keeps the first, second or third own-Movement permission using the core rules' Move Units/ingress terminology.

Shared Necron, Ork, Custodes and Votann transport reminders retain wholly-within placement and the exact disembark eligibility conditions from Core 18.04. A conditional Charge follow-up keeps a prior disembark restriction through its stated turn, including after the carrier is destroyed; it does not assume that an eligible passenger actually embarked or disembarked. Aircraft's Plunging Fire exclusion also appears alongside permitted Movement reactions. The source checks for Core 15.04, 15.06 and 15.11 preserve Insane Bravery's Battle-shock step, Crushing Impact's chosen model in the charging unit, and Heroic Intervention's mode selection before the charge roll and separate distance constraints.
